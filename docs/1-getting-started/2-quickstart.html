2 - Quickstart

Creating a Node (Identity)

To start developing with Yuuko Protocol, you start with creating a node. This is what all other programs on the computer will use to communicate with other devices through Yuuko Protocol.

For this example, let's assume you want to connect a phone and computer.

using System.Text;
using WISecureData;
using YuukoProtocol.Dogma;

var Me = "pc";                      //"phone" on the phone

//DeviceKey locks this device's identity file (8 characters or more), the others lock the saved device list and the folder repository
var DeviceKey = new SecureData(Encoding.UTF8.GetBytes("this device's own password"));    //NOT SecureData.FromString, it wipes the string
var ListKey = new SecureData(Encoding.UTF8.GetBytes("password for the saved device list"));
var RepoKey = new SecureData(Encoding.UTF8.GetBytes("password for the folder repository"));

//The group key is made once, on the first device, and the same one is typed into the others
var GroupKey = Encoding.UTF8.GetBytes(Identity.CreateGroupKey());

//Run all the Start calls here, because pairing builds the node again (CreateNode raises this once too)
Identity.NodeRestarted += async (s, e) =>
{
    SimpleCRDT.Start();
    OpTransform.Start();
    HolyMother.Start();
    await DAG.Start(RepoKey);
    Cogitarium.Start();             //your paired devices (use Nearby.Start() later for strangers)

    //Your own commands also have to be registered again
    Identity.YuukoNode.On("hello", (Context, _) => Task.FromResult(CommandResult.Ok(Encoding.UTF8.GetBytes("hi " + Me))));
};

//Only a device you control may start or stop apps
var CanControl = new HashSet<string> { "phone", "tablet" };
HolyMother.Allow = (Device, Action) => CanControl.Contains(Device);

await Identity.CreateNode(DeviceKey, Me + ".id", Me, true, GroupKey, Me + "-devices.json", ListKey);

//You should optimally save the groupkey so you can use it later, but do so per session

Pairing a Device (Identity)

Great, now how do you connect your PC to your phone? Your PC will show a code and the phone will be what has to type it.

//PC
var Code = await Identity.CreatePairing();
Console.WriteLine(Code);                                            //show it as text or a QR code
Identity.GroupChangeRequested += (s, e) => e.SetResult(true);       //ask the user here instead

//Phone
await Identity.ConnectToDevice(Code, "pc", "phone");
Console.WriteLine(string.Join(", ", Identity.ViewAllConnectedMachines()));      //pc

Sharing a Shopping List's Edits (SimpleCRDT)

For our first example, let's create a shopping list on our laptop and have it sync to the phone.

//PC
var List = new SimpleCRDT.SharedDocs("pc", "Shopping list", DateTime.UtcNow, null);
List.CreateLabel("items", "TSF Rated Paint x10\n");
await SimpleCRDT.CreateNewDoc(List);                     //the phone gets it
List.AddToLabel("items", "TSF Replacement Arm x2\n");                      //and every change after this

//Phone
SimpleCRDT.Start().DocUpdated += (Doc, From) => Console.WriteLine(Doc.ReadLabel("items"));

Editing The Text Of a Note (OpTransform)

Now you have a shopping list but you want to have both devices edit a note at the same time.

//PC (the owner, only the phone may edit)
var Notes = OpTransform.CreateText("notes", "Ideas:\n", new List<string> { "phone" });

//Phone
var Notes = await OpTransform.JoinText("pc", "notes");
Notes.Insert(Notes.Text.Length, "- add Hakodate to the tour\n");
await Notes.WaitUntilSynced(TimeSpan.FromSeconds(5));
Notes.Changed += (Text, Remote, Author) => Console.WriteLine(Text);

Opening An App On PC From Phone (Holy Mother)

Now let's open an app on our laptop from our phone!

//Phone
try
{
    var Apps = await HolyMother.GetApps("pc");
    var Spotify = Apps.First(a => a.Name == "Spotify");
    await HolyMother.StartApp("pc", Spotify.ID);         //throws if the PC refused or is off
}
catch (Exception ex) { Console.WriteLine("Couldn't: " + ex.Message); }

Sharing Folders Between Devices (DAG)

Let's have a folder sync between the phone and laptop now!

//PC
var Folder = await DAG.ShareFolder(@"D:\Movies", new List<string> { "phone" });

//Phone: the same UUID, its own path
await DAG.JoinFolder(Folder.UUID, "/sdcard/Movies", new List<string> { "pc" });
var Result = await DAG.SyncFolder("pc", Folder.UUID);
Console.WriteLine($"{Result.Downloaded} new, {Result.Conflicts.Count} conflicts");

Sharing Live Streamed Data Over Meshnet (Cogitarium)

Using the meshnet system, let's stream data to the phone!

//PC is the source
Cogitarium.JoinChunk("geofront");
var Log = Cogitarium.StartStream("geofront", "Unit-02 vs Angel");
Console.WriteLine("Give the phone this: " + Cogitarium.MyFingerprint);

await Log.Send(Encoding.UTF8.GetBytes("Asuka: Progressive knife, going in"));
await Log.Send(Encoding.UTF8.GetBytes("Angel: AT Field neutralized"));
Console.WriteLine($"{Log.Coverage:P0} of the devices are green");

//Phone: tell the PC how it's doing (so the best get pieces first), accept the PC, and read
Cogitarium.JoinChunk("geofront");
Cogitarium.MyStatus = new Cogitarium.DeviceStatus { WifiStrength = 80, WifiUsage = 25, BatteryPercent = 70, BatteryCapacity = 4000 };
Cogitarium.AcceptSource(FingerprintFromThePC);
Cogitarium.SegmentReceived += (Stream, Piece) => Console.WriteLine(Encoding.UTF8.GetString(Piece.Data));

//Weak mesh? Get it straight from the PC instead
await Cogitarium.SetRoute("geofront", Cogitarium.Route.Auto);

Shutdown

When you want to stop using Yuuko Protocol, simply do

Identity.Shutdown();
