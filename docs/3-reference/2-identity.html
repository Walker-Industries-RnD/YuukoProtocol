2 - Identity

Identity makes this device's node and handles who is connected. Everything else starts from here.

Functions

Function What it does
CreateGroupKey() Makes a new group key. Only for a brand new group: every device must use the same one
CreateNode(Password, DeviceID, DeviceName, ListensToOthers, GroupKey, TrustedDevices, TrustedDeviceKey) Builds and starts this device's node
Shutdown() Stops it. Call it when your app closes
CreatePairing() Opens a pairing window and gives back the code to show
CancelConnecting() Closes the pairing window
ConnectToDevice(Key, DeviceName, DeviceNickname) Pairs using a code the other device showed
ViewAllConnectedMachines() The devices connected right now
IsConnected(name) Is it connected?
HasRecentActivity(name) Has it been heard from recently?
TrustDevice(name) / UntrustDevice(name) Add or remove a device from the group
KickDevice(name, Ban, Reason) Disconnects it, and with Ban keeps it out
UnbanDevice(name) Lets a banned device back
GetLatency(name) How long a round trip takes
YuukoNode The node itself, for your own commands (see 7 - Commands and Devices)

Events: GroupChangeRequested (a device wants to add or remove another, you decide), NodeRestarted (pairing built the node again), ConnectionStatusChange (a kick or ban happened).

Example: start a node

//Both of these are made once, kept, and the same group key is used on EVERY device
var DeviceKey = new SecureData(Encoding.UTF8.GetBytes("this device's own password"));   //locks the identity file, 8 characters or more. NOT SecureData.FromString, it wipes the string
var ListKey = new SecureData(Encoding.UTF8.GetBytes("password for the saved device list"));
var GroupKey = Encoding.UTF8.GetBytes("the group key");                                  //Identity.CreateGroupKey() makes one

//DeviceID is the file this device's identity is kept in, DeviceName is what the others call it
await Identity.CreateNode(DeviceKey, "pc.id", "pc", true, GroupKey, "pc-devices.json", ListKey);

Password locks the identity file (this device's private keys):

  • A new identity is saved encrypted, and an identity file from before there was a password is locked the first time it is loaded with one (it stays the same device).
  • It has to be 8 characters or more. A shorter one, or none, throws.
  • A wrong password throws and the file is left as it was.
  • Keep it separate from the user's own password, and keep it somewhere safe: without it the identity can't be opened, and the device would have to pair again.

ListensToOthers isn't used yet (the node always listens on a free port).

Example: pair two devices

//On the pc: show this
var Code = await Identity.CreatePairing();
Console.WriteLine(Code);                          // YUUKO2-...

//On the phone: type it in (DeviceName is this device, DeviceNickname is what you call the other one)
await Identity.ConnectToDevice(Code, "phone", "pc");

Pairing builds the node again, so run your start-up again afterwards:

Identity.NodeRestarted += (s, e) =>
{
    SimpleCRDT.Start();
    OpTransform.Start();
    HolyMother.Start();
    //...and register your own commands again
};

The code only works for a few minutes and once. CancelConnecting() closes the window early.

Example: who is here

foreach (var Name in Identity.ViewAllConnectedMachines())
{
    var Ping = await Identity.GetLatency(Name);
    Console.WriteLine($"{Name}: {Ping.TotalMilliseconds:F0} ms, recent activity: {await Identity.HasRecentActivity(Name)}");
}

Example: asking the user when a device wants to add another

With nobody listening, group changes are refused. A question left for a minute counts as no.

Identity.GroupChangeRequested += async (sender, e) =>
{
    var Action = e.IsIntroduction ? "trust" : "stop trusting";
    bool Yes = await YourPopup.ShowAsync($"{e.IntroducedBy} wants you to {Action} {e.DeviceId}. Allow?");
    e.SetResult(Yes);
};

await Identity.TrustDevice("tablet");      //asks the other devices to trust it too
await Identity.UntrustDevice("tablet");

Example: kick and ban

await Identity.KickDevice("tablet", Ban: false, Reason: "testing");   //it can come back
await Identity.KickDevice("tablet", Ban: true, Reason: "lost device");
Identity.UnbanDevice("tablet");

Example: closing

Identity.Shutdown();

Finding each other again (Reconnect)

Without this, two paired devices that were turned off have to pair again: the address of the other device was only remembered in memory, and the port could change. Reconnect fixes that.

Reconnect.Open("reconnect.json", FileKey);        //BEFORE CreateNode: loads (or makes) this device's UUID, its port and the paired devices
await Identity.CreateNode(...);
await Reconnect.Start();                          //after CreateNode, and again in NodeRestarted like the other Start calls
Call What it does
Reconnect.Open(Path, Key) Loads or makes the file (encrypted with Key through Pariah's JSONDataHandler). Picks a port once and keeps it
Reconnect.Start() Swaps cards with connected devices, announces where we are when a paired device is missing, tries the missing ones
Reconnect.MyUuid This device's UUID (made once, saved)
Reconnect.Devices The paired devices we remember: UUID, name, key fingerprint, address, last seen
Reconnect.Forget(uuid) Stop looking for one
Reconnect.Found Event: a paired device was found at an address (the node is built again to dial it, so NodeRestarted fires)
Reconnect.Stop() Stops it
Reconnect.BeaconEvery / RetryEvery / AdvertiseHost Settings (10 s, 10 s, the address told to others if the one found is wrong)
