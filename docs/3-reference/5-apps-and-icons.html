5 - Apps and Icons

HolyMother (DOGMA V). See what apps another device has, which are running, start and stop them, and get their pictures.

Apps come from Steam, a WalkerWorks folder, and the apps menu (Start Menu on Windows, .desktop files on Linux). Another device sends an app ID, never a command line, so it can only start what this device listed itself.

Functions

Function What it does
HolyMother.Start() Starts answering other devices. Once, after Identity.CreateNode
HolyMother.LocalApps(Rescan) The apps on this device
HolyMother.LocalRunning() Only the ones open now
HolyMother.GetApps(Device) The apps on another device
HolyMother.GetRunning(Device) Only the ones open now on another device
HolyMother.StartLocal(ID) / StopLocal(ID) Opens / closes one here. Gives back why it couldn't, or null
HolyMother.StartApp(Device, ID) / StopApp(Device, ID) Opens / closes one on another device (throws if it was refused)
HolyMother.LocalIcon(NameOrPath) / LocalIcons(list) Pictures from this device
HolyMother.GetIcon(Device, NameOrPath) / GetIcons(Device, list) Pictures from another device
HolyMother.Allow Asked before another device starts or stops something
HolyMother.WalkerWorksDirectory Where WalkerWorks apps are (one folder per app)

Each app has ID, Name, Source (Steam, WalkerWorks, StartMenu or Desktop) and Running.

Example: look and start

HolyMother.Start();

var Apps = await HolyMother.GetApps("pc");
foreach (var App in Apps) Console.WriteLine($"{App.Name} ({App.Source}) {(App.Running ? "running" : "")}");

var Spotify = Apps.First(a => a.Name == "Spotify");
await HolyMother.StartApp("pc", Spotify.ID);

var Open = await HolyMother.GetRunning("pc");
await HolyMother.StopApp("pc", Spotify.ID);

Example: choosing who may start and stop things

The default allows everything from any device in the group. Say no to block it:

HolyMother.Allow = (Device, Action) => Device == "phone" && Action == "start";      //Action is "start" or "stop"
HolyMother.Allow = (Device, Action) => false;                                        //nobody

Example: pictures

Give a name, an ID, or the path of an app, one or a list:

var Icon = await HolyMother.GetIcon("pc", "Spotify");                                   //bytes of a PNG
var Icons = await HolyMother.GetIcons("pc", new[] { "Spotify", "Steam", Apps[3].ID });   //name -> bytes, the ones with no picture are left out
var Mine = HolyMother.LocalIcon("Spotify");                                              //this device

File.WriteAllBytes("spotify.png", Icon);

Lists are queued: if you ask for several lists at once they go one at a time in the order they came, and a long list is asked for in batches so each answer fits in a command. A picture you already fetched isn't asked for again.

On Windows the picture is the program's icon as a PNG. On Linux it's the icon file (a PNG, or an SVG). Check the first bytes if you need to know which.

Another device can only ask about apps this device listed. A path only works if it's the path of one of them, so it can't be used to look at other files.

Example: apps on this device

var Here = HolyMother.LocalApps();
foreach (var App in Here) Console.WriteLine(App.Name);

var Problem = HolyMother.StartLocal(Here[0].ID);        //null means it worked
if (Problem != null) Console.WriteLine(Problem);

Things to know

  • Stopping asks the app to close, and ends it after 2 seconds. It matches by program, so it closes every copy of that program.
  • A Start Menu shortcut that has arguments (it runs through powershell, cmd or a browser) and a Linux entry that runs through flatpak, snap or env can be started but not stopped: we can't tell which process is theirs.
  • The default of Allow is "yes". Set it before you let any device control apps.
  • WalkerWorks apps: a folder per app, the app is the file named like the folder (Name.exe, Name.xur, or Name).
