7 - Commands and Devices

The layer underneath everything else: your own commands between devices, the list of paired devices, and pairing codes. Identity.YuukoNode is the node (an EclipseBroker).

Use it when none of the other pages fit: copying a clipboard, handing music to another device, any "do this once on that device".

Commands

Function What it does
node.On(command, handler) Answers a command. The handler gets the sender and the bytes, and returns CommandResult.Ok(...), Error(...) or Denied(...)
node.Off(command) Stops answering it
node.SendCommandAsync(peer, command, payload) Sends a command to one device and waits for its answer (IsOk, Status, Result, Message)
node.BroadcastAsync(command, payload) Sends it to every connected device (signed, passed on by devices that are in range of each other but not of you)
node.PingAsync(peer) A round trip, Elapsed says how long

A command is at most 1 MB. A command that is sent twice by mistake (a retry) only runs once on the other device.

Peers

Function What it does
node.ConnectedPeers / node.Peers Who is connected
node.IsConnected(peer) / IsOnline(peer) / LastSeen(peer) Presence
node.KickAsync(peer, ban) / Unban(peer) Disconnect, keep out, let back
node.PeerConnected / PeerDisconnected Events
node.ClientId / Fingerprint This device's name and key fingerprint

Devices you paired

Function What it does
node.Device(name) One device: SendAsync, SendTextAsync, PingAsync, KickAsync, IsConnected, IsOnline, LastSeenUtc
node.AllDevices() All of them as a set: OnlineOnly(), Except(names), SendAsync(command, payload)
node.DeviceGroup(group) The ones you put in a group ("phones")
node.DeviceStatuses() Name, connected, online, last seen, for each
node.Devices The saved list (DeviceDirectory): All, Find, FindByClientId, FindByFingerprint, InGroup, Add, Remove, Rename, SetGroups, event Changed
node.PairDevice(...) / UnpairDeviceAsync(name, kick) Add / remove one by hand
node.BeginPairing() / CancelPairing() / PairingOpen Pairing window (Identity.CreatePairing wraps this)
node.PairWithAsync(code, moniker) Pair using a code (Identity.ConnectToDevice wraps this)
node.IntroduceAsync(deviceId) / RevokeAsync(deviceId) Ask the others to trust / stop trusting a device

Pairing codes

Function What it does
PairingCode.Parse(text) / TryParse(text, out code, out error) Reads a YUUKO2-... code
code.Encode() The text again
code.DeviceId, Fingerprint, Endpoint, ExpiresUtc, IsExpired What's in it
code.ToTransportOptions(deviceName) The transport settings needed to reach that device

Example: your own command

//On the pc: answer it
Identity.YuukoNode.On("hello", (Context, Cancel) =>
    Task.FromResult(CommandResult.Ok("hi " + Context.Origin + ", you sent " + Context.PayloadAsString())));

//On the phone: send it
var Ack = await Identity.YuukoNode.SendCommandAsync("pc", "hello", Encoding.UTF8.GetBytes("test"));

if (Ack.IsOk) Console.WriteLine(Encoding.UTF8.GetString(Ack.Result));      //hi phone, you sent test
else Console.WriteLine($"{Ack.Status}: {Ack.Message}");

Context.Origin is the device that started it. It is checked, a device can't pretend to be another.

Example: tell everyone (a clipboard)

//Sending
await Identity.YuukoNode.BroadcastAsync("clipboard.set", Encoding.UTF8.GetBytes(Text));

//Receiving
Identity.YuukoNode.On("clipboard.set", (Context, Cancel) =>
{
    if (Context.Payload.Length < 100_000) SystemClipboard.Set(Context.PayloadAsString());
    return Task.FromResult(CommandResult.Ok());
});

Don't send a clipboard change that you only just received, or two devices pass it back and forth forever.

Example: say no to a command

Identity.YuukoNode.On("shutdown", (Context, Cancel) =>
    Task.FromResult(Context.Origin == "pc" ? CommandResult.Ok() : CommandResult.Denied("only the pc may")));

Example: the device list

var Node = Identity.YuukoNode;

foreach (var Status in Node.DeviceStatuses()) Console.WriteLine($"{Status.Moniker}: online={Status.IsOnline}");

await Node.Device("pc").SendTextAsync("hello", "hi");

var Acks = await Node.AllDevices().OnlineOnly().SendAsync("hello", Encoding.UTF8.GetBytes("hi"));   //name -> answer
foreach (var (Name, Ack) in Acks) Console.WriteLine($"{Name}: {Ack.Status}");

Node.PeerConnected += Peer => Console.WriteLine(Peer.Id + " connected");

Example: groups

Node.Devices.SetGroups("phone", new[] { "phones", "mobile" });
Node.Devices.SetGroups("tablet", new[] { "mobile" });

await Node.DeviceGroup("mobile").SendAsync("notice", Encoding.UTF8.GetBytes("hello"));

Things to know

  • Your command names should have a prefix so they don't clash (clipboard., music.). The library's own are crdt., ot., holy., dag..
  • Handlers run on a background thread and may take a while, but not forever (there's a time limit).
  • A command that throws becomes an error answer that names only the exception type, never the message.
  • Pairing builds the node again, so commands you registered with On are gone: register them again after Identity.NodeRestarted.
  • Audit what a device decided with 9 - Audit Log.
