0 - All Functions

Below is a list of all the functions you will most likely use alongside why. For examples and the details, follow the page links. The calls are in the order you'd use them.

Start (once, in this order)

Call What it does
Identity.CreateNode(Password, DeviceID, DeviceName, ListensToOthers, GroupKey, TrustedDevices, TrustedDeviceKey) Makes and starts this device's node
Identity.CreatePairing() Opens the pairing window, gives back the code to show
Identity.ConnectToDevice(Code, DeviceName, DeviceNickname) Pairs with a device using its code
SimpleCRDT.Start() Turns on shared documents
OpTransform.Start() Turns on shared text
HolyMother.Start() Turns on apps (other devices can list, start and stop)
DAG.Start(key) Turns on folder sync
Cogitarium.Start() Turns on stream sharing between your paired devices
Nearby.Start() Turns on stream sharing with devices you don't know on the same network (replaces Cogitarium.Start())
Reconnect.Open(Path, Key) BEFORE CreateNode: this device's UUID, its fixed port and the paired devices' addresses (encrypted file)
Reconnect.Start() After CreateNode and in NodeRestarted: paired devices find each other again after being off
Identity.NodeRestarted Event: pairing built the node again, run the four Start calls again
Identity.Shutdown() Stops the node when your app closes

Devices (2 - Identity)

Call What it does
Identity.ViewAllConnectedMachines() Names of the devices connected now
Identity.IsConnected(name) Is it connected?
Identity.HasRecentActivity(name) Has it been heard from lately?
Identity.GetLatency(name) Round-trip time
Identity.TrustDevice(name) / UntrustDevice(name) Add / remove a device from the group
Identity.KickDevice(name, Ban, Reason) Disconnect it (and keep it out with Ban)
Identity.UnbanDevice(name) Let a banned device back
Identity.CancelConnecting() Close the pairing window
Identity.CreateGroupKey() Make a new group key (once, for a new group)
Reconnect.MyUuid / Devices / Forget(uuid) / Found This device's UUID / the paired devices we remember / forget one / event: one was found at a new address
Identity.GroupChangeRequested Event: a device wants to add or remove another, answer with SetResult(true/false)
Identity.ConnectionStatusChange Event: a kick or ban happened

Your own commands (7 - Commands and Devices)

Call What it does
Identity.YuukoNode.On(command, handler) Answer a command
Identity.YuukoNode.Off(command) Stop answering it
Identity.YuukoNode.SendCommandAsync(device, command, bytes) Send a command to one device and wait for the answer
Identity.YuukoNode.BroadcastAsync(command, bytes) Send a command to every connected device
Identity.YuukoNode.PingAsync(device) Round trip to one device
Identity.YuukoNode.Device(name) One paired device (SendAsync, SendTextAsync, PingAsync, KickAsync)
Identity.YuukoNode.AllDevices() All paired devices as a set (OnlineOnly(), Except(), SendAsync())
Identity.YuukoNode.DeviceGroup(group) The devices you put in a group
Identity.YuukoNode.DeviceStatuses() Name, connected, online and last seen for each device
Identity.YuukoNode.PeerConnected / PeerDisconnected Events: a device came or went
CommandResult.Ok(...) / Error(...) / Denied(...) What a handler gives back

Shared documents (3 - Shared Documents)

Call What it does
new SimpleCRDT.SharedDocs(DeviceName, LabelName, LastUpdated, null) Makes a document
doc.CreateLabel(Label, Content) Adds a text field with a first value
SimpleCRDT.CreateNewDoc(doc) Shares it with every connected device
doc.ReadLabel(Label) / doc.ReadDoc() Reads one field / all of them
doc.AddToLabel(Label, Content, Overwrite) Adds at the end, or replaces the field with Overwrite
doc.CreateText(Label, Content) Adds text at the end of a field
doc.DeleteFromLabel(Label, Start, End) Removes part of a field
doc.NukeLabel(Label, DeleteLabel) Empties a field (and removes it)
SimpleCRDT.ItemList The documents this device has, by UUID
SimpleCRDT.RemoveDoc(uuid) Removes a document everywhere
SimpleCRDT.SyncAll() Compares with every device now
SimpleCRDT.Start().DocReceived / DocUpdated / DocRemoved Events: a document arrived, changed, or was removed
SimpleCRDT.MaxDocs / MaxLabels / ChunkBytes / MaxChunkedBytes Settings: documents kept (no limit), labels per document (256), size of a piece (500 KB), biggest thing put back together (128 MB)

Shared text (4 - Shared Text)

Call What it does
OpTransform.CreateText(Name, Content, Writers) Makes a text this device owns
OpTransform.JoinText(OwnerDevice, Name) Joins a text another device owns
OpTransform.GetText(Name) A text this device already has
OpTransform.TextList Names of the texts here
OpTransform.RemoveText(Name) Stops taking part
text.Text The newest text
text.Insert(Index, Content) / Delete(Index, Length) / Replace(Index, Length, Content) Edits
text.SetText(Content) Replaces everything (keeps other people's typing)
text.IsSynced / text.WaitUntilSynced(Timeout) Are my edits confirmed? / wait until they are
text.Changed / text.Rejected Events: it changed / the owner refused my edit

Apps and icons (5 - Apps and Icons)

Call What it does
HolyMother.GetApps(Device) Apps installed on another device
HolyMother.GetRunning(Device) Apps open on another device
HolyMother.StartApp(Device, ID) / StopApp(Device, ID) Opens / closes an app on another device
HolyMother.GetIcon(Device, NameOrPath) One app's picture from another device
HolyMother.GetIcons(Device, list) Pictures for a list of apps (queued, in batches)
HolyMother.LocalApps() / LocalRunning() The same, for this device
HolyMother.StartLocal(ID) / StopLocal(ID) Opens / closes an app here
HolyMother.LocalIcon(NameOrPath) / LocalIcons(list) Pictures from this device
HolyMother.Allow Your check, asked before another device starts or stops something
HolyMother.WalkerWorksDirectory Where WalkerWorks apps are

Folder sync (6 - Folder Sync)

Call What it does
DAG.ShareFolder(Path, Devices) Shares a folder from this device, gives back the UUID
DAG.JoinFolder(UUID, Path, Devices) Joins a folder another device shared, with your own path
DAG.CheckIfFolderExists(Device, UUID) Does that device share it with us?
DAG.CheckForUpdate(Device, UUID) Does it have something different?
DAG.SyncFolder(Device, UUID) Gets what that device has, gives back what happened
DAG.ResumeFolder(Device, UUID, Tries) Syncs, and if some files failed waits a second and syncs again, so a stopped sync is pushed to the end
DAG.BroadcastUpdate(UUID) Tells everyone this folder changed here
DAG.StopSharing(UUID) Stops sharing (files stay)
DAG.AutoSync / AllowMassDelete / RepoPath Settings
DAG.MaxFiles / MaxFileBytes Settings: files in a folder and size of one file (no limit unless set)
DAG.FolderUpdated / Progress / Problem Events: something changed / download progress / a background problem

The Cogitarium: nearby streams (8 - Collective Distribution)

Call What it does
Cogitarium.JoinChunk(ChunkID) / LeaveChunk(ChunkID) Be part of an area's mesh / leave it
Cogitarium.AcceptSource(Fingerprint) / RejectSource(Fingerprint) Accept (and pass on) or stop accepting a source's streams
Cogitarium.MyFingerprint What others accept this device by
Cogitarium.StartStream(ChunkID, Name) Makes this device a source
stream.Send(Data, Level) Signs a piece and sends it to the best few devices
Cogitarium.SegmentReceived Event: a piece arrived
Cogitarium.Want(ChunkID, Levels...) Which sizes this device wants
Cogitarium.Neighbors(ChunkID) Who is connected to us in that chunk
Cogitarium.Offers / StreamOffered / Accept(offer) Streams from sources we haven't accepted: see them, then take one
Cogitarium.MyStatus Tell neighbors how we're doing (wifi, usage, battery, battery size) so the best get pieces first
stream.Mains / Ratings() / Suspects() / Coverage The source's main devices, what devices say about each, who was left out, share that is green
Cogitarium.SetRoute(ChunkID, Route) Get a chunk from the mesh (Mesh), straight from the source (Internet) or Auto
Cogitarium.Distrust(Device) / Forgive(Device) / IsDistrusted(Device) Who we trust to pass things on
Cogitarium.DeviceDistrusted Event: we stopped trusting a device
Nearby.Start(IdentityPath) / Stop() Find and join strangers on the network / leave
Nearby.Start(Transport) / Start(null, Address) The same on a link the app built / also call an address (Wi-Fi Direct group owner)
Nearby.MyID / Neighbors / MaxNeighbors The random ID others see / who is connected / the most we keep
Nearby.MyCard / People / Passed / Forget(fingerprint) Streetpass: the card we hand out / who we met / event: met someone / forget one

Audit log (9 - Audit Log)

Call What it does
AuditLog.Open(path, key) Opens a log to read and add to
AuditLog.OpenReadOnly(path, key) Opens it so it can be read but never changed
log.Attach(node) Records the node's decisions by itself
log.Append(kind, subject, detail) Adds your own entry
log.Read(kind) Reads the entries
log.Verify() Checks nothing was changed or removed
log.Seal() Makes the file read-only for good
AuditLog.Open(path, key, signer) The same, with every entry signed by the device's own key (a key holder can't forge it)
log.AnchorTo(node, name) Sends the newest head to the connected devices after every entry
new AuditWitness(node, path, key) On the devices that watch: remembers the heads they are told
log.VerifyWithWitnessesAsync(node, name, expectedSigner) Verify, then ask the others what they saw (cut off ends, rewrites)

Pairing codes

Call What it does
PairingCode.Parse(text) / TryParse(...) Reads a YUUKO2-... code
code.Encode() The code as text
code.IsExpired / ExpiresUtc Is it still good?

Remember

  • Run all the Start calls again after Identity.NodeRestarted.
  • Use the same device names everywhere ("pc", "phone").
  • Calls that ask another device can fail when it is off: use try/catch.
  • HolyMother.Allow says yes to everything until you set it.
